# Start Here

This package replaces the earlier Project 2 prototype. It is the final foundation for Steps 1–3.

1. Extract into a fresh `Enterprise Application Support Copilot` folder.
2. Create and activate `.venv`.
3. Install `requirements.txt`.
4. Copy `.streamlit/secrets.toml.example` to `.streamlit/secrets.toml`.
5. Run `python -m streamlit run app.py`.
6. Run page 2 ingestion, then inspect page 3 chunks and audit history.
